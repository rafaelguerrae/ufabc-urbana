# ufabc-urbana

Esse é o meu projeto para a disciplina de Projeto Dirigido do curso de Bacharel em Ciência e Tecnologia

## O que é o UFABC Urbana

Basicamente, o Urbana é um projeto de análise de dados de temperatura em áreas urbanas, dando a possibilidade do usuário experimentar de forma própria como a vegetação pode trazer benefícios ao meio ambiente, ainda mais em regiões tão urganizadas como São Paulo e o Grande ABC.
